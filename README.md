# Dom Aromatov — сайт

Статичный сайт (HTML/CSS/JS, без сборки) для магазина отливантов Dom Aromatov.

- `data.js` — **всё, что нужно менять**: номер WhatsApp, цены по объёмам, список ароматов (бренд, название, ноты, пол, семейство, цвет).
- `index.html`, `styles.css`, `app.js` — вёрстка, стили, логика каталога и сэта.
- `assets/` — фото ведущей, логотип, иконка.

Заказ оформляется сообщением в WhatsApp. Корзина хранится в браузере покупателя.
Деплой: Vercel, как статический сайт (Framework: Other, без build-команды).
